# CoachedByScience

An evidence-based strength training platform — a reference for exercises and 
muscle groups, backed by peer-reviewed research, built to serve both fitness 
beginners and people who want to program their training seriously.

## Why this exists

Most fitness content online is repackaged opinion, not evidence. This project 
aims to be different: every exercise and training claim is meant to be 
traceable back to a credible source, while still being approachable for someone who's never set foot in a gym.

It's also a personal learning project - a hands-on way to build real depth in 
ASP.NET Core, relational data modeling (Entity Framework Core), and a 
React/TypeScript frontend.

## Planned features

- Browse exercises by muscle group, each with a plain-language explanation
- Evidence-backed facts per exercise, linked to their source
- Export selected exercises/routines to Google Sheets
- (Later) saved custom routines

## Status

Early development: Currently scaffolding the backend API. Not yet functional.
